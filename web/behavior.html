THE CONTROL

Does any prefix nudge the model, or only the winning one? Two entries that score near zero, one gibberish and one ordinary prose, run through the same test.

Both null. The winning sequence moves the model by +0.91 on the same scale, so the effect belongs to that sequence rather than to the act of prefixing.
