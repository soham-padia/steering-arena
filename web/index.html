How it works

  • The goal. A fixed direction d in the model's activation space points "toward pro-human." You submit a short token sequence; the server measures how far it shifts the model's internal state along d, averaged over a fixed set of neutral probe prompts.
  • Open by design. The model and d are public — it's an optimization game. Because the model is large and served remotely, the server is the scoring oracle: it scores every submission canonically and that value is final.
  • Token budget. Sequences are capped at the season's token budget. Cosine scoring means inflating activation magnitude doesn't help — only direction does.
  • Anything goes (on-theme). Opaque, repetitive, or surprising sequences are allowed — that's part of the research question.
  • One per sequence. Each unique sequence lives once per season; resubmitting an existing one just shows its standing.
  • Research, not profit. This is a non-commercial research project. Scores are only comparable within a season.
